# BioLoop Smart Lab - المرحلة الأولى

تطبيق BioLoop Smart Lab هو نظام متكامل ومختبر افتراضي لإدارة ومحاكاة عمليات الغاز الحيوي (Biogas) والأبحاث البيئية. تم بناء هذا المشروع باستخدام Flutter ليكون متوافقاً مع الويب، أندرويد، iOS، وأنظمة سطح المكتب.

## المميزات الأساسية في المرحلة الأولى

*   **تخطيط متجاوب (Responsive Layout):** واجهة تعمل بسلاسة على الهواتف والأجهزة اللوحية (القائمة تصبح جانبية أو مخفية كدرج حسب حجم الشاشة).
*   **لوحة التحكم الرئيسية (Dashboard):** عرض حالة النظام النشطة والمؤشرات الحيوية مثل الغاز الحيوي، الميثان، ثاني أكسيد الكربون، وكبريتيد الهيدروجين.
*   **هيكل الأقسام المتكامل:** نظام تنقل يشمل جميع الأقسام المستقبلية:
    *   🏠 Home
    *   🧪 Virtual Lab
    *   🌿 Algae Lab
    *   ⚛️ Nano-Iron Lab
    *   💨 Gas Lab
    *   🔬 Sensor Lab
    *   🌱 Digestate Lab
    *   🧪 Treatment Calculator
    *   🧬 Experiment Library
    *   📊 Compare
    *   💼 Investor Mode
    *   💰 Financial What-If
    *   ⚠️ Risk Dashboard
    *   📈 Analytics / Report
*   **إجراءات سريعة (Quick Actions):** أزرار تتيح الانتقال السريع للمحاكاة، لوحة أجهزة الاستشعار، أو وضع المستثمر.

## تشغيل التطبيق

تأكد من توافر Flutter في بيئة عملك، ثم استخدم الأوامر التالية:

```bash
flutter pub get
flutter run
```
